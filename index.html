❓ CosyUI Guide & Node Dictionary

Quick Start Guide

CosyUI combines a Visual Logic Graph (backend) with a Dynamic Player UI (frontend):

  • Nodes represent operations: user inputs, prompt builders, LLMs, dice rollers, stat bars, and chatboxes.
  • Trigger Sockets (Orange) control execution flow (when nodes execute).
  • Data Sockets (Colored) pass data (text, numbers, JSON, inventory items).
  • UI Nodes automatically mount onto the Player View to customize the game UI.
